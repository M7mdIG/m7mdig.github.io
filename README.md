# m7mdig.github.io

Personal portfolio site for Mohamed Gaaboub with a focused intro, detailed about section, highlighted projects, and contact options. Open `index.html` in a browser to explore the layout.

## Preview
- Intro screen with CTA buttons and quick skill chips.
- About section covering principles, toolbox, collaboration style, and upcoming interests.
- Projects grid populated via JavaScript with thumbnails, descriptions, and tech tags.
- Contact section featuring direct links and a lightweight inquiry form.

## Getting started
1. Clone the repository.
2. Open `index.html` in your preferred browser.
3. Customize the `projects` array in the inline script to showcase your own work, thumbnails, and stacks.
4. Update the contact details (email and LinkedIn) and hero messaging to match your preferences.
